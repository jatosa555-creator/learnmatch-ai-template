# LearnMatch AI (คู่มือภาษาไทย)

แม่แบบเกมการเรียนรู้ที่เปลี่ยนหัวข้อได้ด้วย AI โดยระบบเกมอยู่แยกจากข้อมูลเนื้อหา

## เริ่มใช้งาน

```bash
npm install
npm run validate:content
npm run dev
```

แก้หัวข้อใหม่ที่ `content/items.json` และเพิ่มรูปที่ `public/assets/` โดยไม่ต้องแก้ระบบเกมหลัก

- Basic: 6 คน, 12 ใบ, กระดาน 3×4
- Advanced: 10 คน, 20 ใบ, กระดาน 4×5
- คะแนนเต็ม 100: จบเกม 30 + ความแม่นยำ 50 + ความเร็ว 20

ตัวอย่างที่ให้มาคือบุคคลสำคัญด้าน STEM ภาษาไทย ส่วนโค้ด คู่มือ และ Prompt หลักเป็นภาษาอังกฤษเพื่อให้ใช้ต่อได้ทั่วโลก

ตรวจชื่อ ข้อเท็จจริง แหล่งข้อมูล เครดิต และสิทธิ์รูปภาพก่อนเผยแพร่ทุกครั้ง
