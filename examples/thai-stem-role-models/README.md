# Thai STEM Role Models Example

This is the bundled Thai example content pack for LearnMatch AI. It demonstrates bilingual titles, fields, descriptions, facts, source links, and image metadata.

The active copy is currently loaded from `content/items.json` so the public demo remains unchanged during the migration. To create a different subject, copy this format into a new example folder and update the active content pack.

The public template uses generated placeholders for this example. Replace each placeholder with a rights-cleared image and update its credit and license before publication.
